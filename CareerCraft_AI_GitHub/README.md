# CareerCraft AI

**Your career, clearly presented.**

CareerCraft AI is a fully static, browser-based AI-style resume builder and ATS/job matcher designed for students and job seekers.

## Live deployment

This project is designed for **GitHub Pages**. No Python, database, API key, Firebase account, MongoDB, server, or build command is required.

### Deploy in under 2 minutes

1. Create a new GitHub repository, for example `careercraft-ai`.
2. Upload **all files in this folder** to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the live website URL.

## Important note

The ATS checker is a lightweight client-side keyword analyzer, not a replacement for a commercial ATS. It does not send resume data to a server.

The app intentionally avoids inventing achievements or credentials. Add only information that is true for you.

## Portfolio description

> CareerCraft AI is a fully responsive, browser-based resume platform that helps students create professional ATS-friendly resumes, preview them live, analyze job-description keyword matches, identify missing skills, and export the final resume through the browser's PDF print workflow. Built with HTML, CSS and vanilla JavaScript and deployed on GitHub Pages.
